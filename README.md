# nojstd — IDE для диаграмм машин Тьюринга

nojstd — веб-приложение для создания, редактирования и отладки диаграмм машин Тьюринга. Визуальный редактор позволяет строить операционные диаграммы, задавать алфавит и правила переходов, запускать машину на ленте и проверять её на тестовых данных.

## Возможности

- **Редактор диаграмм:** создание и редактирование операционных узлов, переходов и условий ветвления; перемещение и выделение элементов, автоматическая раскладка, отмена и повтор действий.
- **Операции машины:** начало и завершение, сдвиг головки, поиск пустой ячейки, запись символа и вызов вложенной подмашины. Диаграмму можно также строить с помощью VTM-кода.
- **Алфавит и лента:** готовые и пользовательские алфавиты, выбор обозначения пустого символа, редактирование двусторонней ленты и начального положения головки.
- **Проверка и отладка:** статический анализ диаграммы, пошаговое выполнение с возвратом назад, запуск и пауза, быстрый запуск и пакетные тесты.
- **Управление проектами:** несколько диаграмм, поиск, дублирование и удаление проектов. Проекты сохраняются в `localStorage` браузера.

## Импорт и экспорт диаграмм

- **Импорт JSON:** в менеджере проектов нажмите «Импорт» и выберите ранее экспортированный JSON-файл проекта.
- **Экспорт JSON:** сохраните проект из менеджера проектов или через окно экспорта. JSON предназначен для последующего импорта и продолжения работы.
- **Экспорт для отчётов:** окно экспорта поддерживает LaTeX, TikZ, PlantUML и Markdown.
- **Экспорт изображения:** диаграмму можно скачать в формате PNG или SVG.
- **Повторное использование:** существующую машину можно импортировать в VTM-код как функцию или использовать как подмашину.

Форматы отчётов и изображений предназначены для публикации; для обмена редактируемыми проектами используйте JSON.

## Запуск

Требуются Node.js и npm.

```bash
# Перейдите в каталог клонированного репозитория
cd nojstd8

# Установите зависимости и запустите сервер разработки
npm install
npm run dev
```

Другие команды:

```bash
npm test                 # тесты
npm run test:watch       # тесты в режиме наблюдения
npm run typecheck        # проверка типов TypeScript
npm run build            # production-сборка
npm run preview          # предпросмотр сборки
npm run check            # проверка типов, тесты и сборка
npm run check:graph      # проверка актуальности артефактов Graphify
```

## Особенности симуляции

Симулятор работает с одной двусторонней разреженной лентой и выполняет машину детерминированно; многоленточные и недетерминированные вычисления с поиском по ветвям не поддерживаются. Детектор циклов хранит последние 256 конфигураций и поэтому обнаруживает не все возможные циклы. Быстрый и пакетный запуск по умолчанию ограничены 10 000 шагов.

## Устройство проекта

Приложение построено на React, TypeScript, React Flow, Zustand и Tailwind CSS; сборка выполняется Vite, тесты — Vitest.

```text
src/
├── components/
│   ├── canvas/       # редактор диаграмм, узлы, переходы и инспектор
│   ├── inspector/    # диагностика и ввод VTM-кода
│   ├── navbar/       # навигация и окно экспорта
│   ├── sidebar/      # проекты и алфавиты
│   └── tape/         # лента, отладчик и пакетные тесты
├── engine/           # симулятор, проверка, преобразование и экспорт
├── store/            # состояние Zustand, сохранение и примеры проектов
├── hooks/            # клавиатурные сочетания
├── types/            # типы диаграмм, правил и проектов
├── utils/            # раскладка и экспорт изображений
├── App.tsx
└── main.tsx
```
