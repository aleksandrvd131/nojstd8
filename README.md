# Next-Gen Turing Machine IDE & Diagrammer (Интерактивный Диаграммер и Симулятор Машин Тьюринга)

Современная веб-среда (SPA) для моделирования, визуализации и отладки классических и операционных машин Тьюринга. Приложение разработано на базе React 18, TypeScript, `@xyflow/react` (React Flow v12), Zustand и TailwindCSS.

---

## 🌟 Ключевые возможности

### 1. Поддержка двух фундаментальных математических режимов
- **Режим в пятёрках (5-tuple mode)**:
  - Формат перехода: $(q, a, a', d, q')$, где $d \in \{L, R, N\}$. За один такт машина одновременно перезаписывает символ и сдвигает головку.
  - Визуализация в виде графа состояний ($q_0, q_1, \dots$), начальное состояние и состояния останова (Halt / Accept / Reject).
- **Режим в четвёрках (4-tuple mode)**:
  - Формат перехода: $(q, a, C, q')$, где $C \in \Sigma \cup \{L, R, N\}$. За один такт машина либо выполняет сдвиг, либо записывает символ.
  - **Два синхронизированных подрежима**:
    1. *Граф состояний в четвёрках*: узлы — состояния, метки дуг — `read : command`.
    2. *Операционная диаграмма Тьюринга (в стиле VTM)*: академический стандарт курсов теории алгоритмов. Узлами выступают элементарные операции машины (`START`, `FINISH`, сдвиги `l` и `r`, поиск до пустого `L` и `R`, запись `[a]`, вложенные подмашины), а рёбра содержат условия ветвления по считанному символу (`a`, `*`, `¬a`).
- **Двусторонний автоматический транспилятор**:
  - Конвертация $5\text{-tuple} \leftrightarrow 4\text{-tuple}$ с автоматическим расщеплением совмещённых шагов через генерацию вспомогательных состояний $q_{\text{aux}}$.
  - Автоматическая компиляция операционной диаграммы VTM в каноническую таблицу четвёрок.

### 2. Специализированный движок графов на `@xyflow/react`
- **Группировка параллельных правил (Multi-Rule Edge Bundling)**: правила между состояниями объединяются в одно ребро и рендерятся в виде интерактивных плашек.
- **Кастомные петли (SelfConnectingEdge)**: замкнутые петли переходов узла в самого себя над верхней гранью узла.
- **Разведение встречных дуг (BiDirectionalEdge)**: автоматический расчёт ортогонального смещения кривой Безье для встречных переходов $A \to B$ и $B \to A$.
- **Автоматическая укладка графа**: интеграция с библиотекой `dagre` для мгновенного упорядочивания вершин в один клик.

### 3. Менеджер алфавитов и живой рефакторинг
- Готовые пресеты: Бинарный (`0, 1`), Унарный с маркерами (`1, *, x, =`), Десятичный (`0–9`), Шестнадцатеричный (`0–9, A–F`), Символьно-логический (`#, $, 1, 0, T, F`).
- Конструктор произвольных пользовательских символов.
- Выбор отображения пустого символа: `_`, `λ`, `␣`, `a0`.
- **Живой рефакторинг (Live Refactoring)**: при переименовании символа в алфавите он автоматически обновляется во всех правилах переходов, на холсте, в таблицах и на ленте.

### 4. Двусторонняя синхронизация представлений
- Вкладка **Таблица**: табличный редактор в 4 или 5 столбцов с подсветкой активного правила в реальном времени.
- Вкладка **Матрица**: двумерная матрица переходов (Символы $A \times$ Состояния $Q$). Редактирование любой ячейки мгновенно отражается на холсте.
- Вкладка **Check (Статический анализатор)**: автоматическая верификация графа перед запуском (проверка ровно одной точки входа START, наличия HALT/FINISH, детерминированности, выявление изолированных узлов).

### 5. Бесконечная лента и пошаговый отладчик
- Двусторонне-бесконечная разреженная лента (`Record<number, string>`) с интерактивным редактированием ячеек и строковым вводом слова.
- Буфер начального состояния (сохранение в буфер и сброс ленты).
- Управление исполнением: **Step Forward** (шаг вперед), **Step Back** (шаг назад по истории снимков), **Run / Pause** с плавным регулированием скорости (от 30 до 800 мс).
- Метрики вычислительной сложности:
  - **Временная сложность**: количество выполненных тактов.
  - **Пространственная сложность**: количество задействованных ячеек ленты.
- Вкладка **Пакетное тестирование (Multiple Run)**: набор тест-кейсов с автоматической валидацией результирующего слова на ленте.

### 6. Персистентность сессий и модуль экспорта
- Автосохранение всех сессий в `localStorage` браузера через Zustand persist.
- Боковая панель менеджера проектов: поиск, дублирование, удаление, текстовое поле для формулировки условия задачи.
- Экспорт в форматы:
  - **JSON** (полный дамп проекта и импорт);
  - **LaTeX** (формальное определение $M = \langle Q, \Sigma, \Gamma, \delta, q_0, B, F \rangle$ и таблицы переходов для лабораторных отчётов);
  - **PlantUML** (спецификация диаграммы состояний);
  - **Markdown** (таблицы в формате GitHub Flavored Markdown);
  - **PNG** (высококачественный графический снимок холста).
